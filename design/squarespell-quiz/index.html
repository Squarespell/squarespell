A few good questions

Before your
first question.

Is this only for Squarespace websites?

No. Squarespell Quiz is designed for multiple platforms. Start with a hosted link or an embed where your website supports it. Installation steps vary by platform and plan; choose your platform above to see the intended path.

Will it automatically add a quiz to my site?

Not on every platform. Some platforms require you to add a code or embed block yourself. In particular, connecting a Squarespace account does not automatically insert a quiz into an ordinary page. The install flow must explain the available steps clearly.

What happens when I reach my monthly limit?

You receive usage warnings and a grace allowance. If collection pauses, visitors can still finish anonymously and see a result. The lead form is hidden. Existing leads remain available to view and export; collection resumes on upgrade or the monthly reset.

Is this the same as the one-time Squarespell plugin?

No. Squarespell Quiz is a separate subscription product operated by Squarespell Limited. The marketplace and its one-time quiz plugin remain at squarespell.com. An existing plugin purchase does not automatically become a Quiz subscription.

Can I try the quiz without giving my email?

Yes. The interactive example on this page asks no personal questions, sends no answers to a server, and resets when you reload. It demonstrates a visitor experience; it does not create an account or a live quiz.
